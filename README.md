# مِرْساة — مراجعة الامتحانات

تطبيق PWA عربي خفيف للمراجعة والتدريب على أسئلة الامتحانات. الواجهة مبنية بـ HTML وCSS وJavaScript عادي، والـ API يعمل عبر Cloudflare Pages Functions مع Cloudflare D1.

## الملفات الأساسية

| الملف | الغرض |
|---|---|
| `index.html` و`styles.css` و`app.js` | واجهة الطالب والمعلم والمنطق التفاعلي |
| `manifest.json` و`sw.js` و`assets/icon.svg` | قابلية التثبيت والعمل الأساسي دون اتصال |
| `schema.sql` | جداول D1 والفهارس والعلاقات |
| `functions/api/[[path]].js` | API تسجيل الدخول والأسئلة والمحاولات والإحصائيات |
| `wrangler.toml` | تعريف مشروع Pages وربط D1 |

## التشغيل المحلي للواجهة

يمكن فتح `index.html` مباشرة لمراجعة الواجهة؛ وفي هذه الحالة يستخدم التطبيق أسئلة تجريبية محفوظة داخل `app.js`، لأن API وD1 غير متاحين عبر فتح الملف مباشرة. لاختبار الـ PWA وservice worker استخدم خادمًا محليًا ثابتًا مثل `npx serve .` أو امتداد Live Server، ثم افتح عنوان localhost.

## إعداد D1

أنشئ قاعدة بيانات باسم `exam_review_db` من لوحة Cloudflare أو باستخدام Wrangler، ثم استبدل `database_id` في `wrangler.toml` بالمعرّف الحقيقي. طبّق المخطط بالأمر التالي بعد تثبيت Wrangler وتسجيل الدخول:

```bash
npx wrangler d1 execute exam_review_db --remote --file=schema.sql
```

أنشئ هاش SHA-256 لكلمة مرور المعلم، ثم أضف حسابه إلى D1:

```bash
printf 'كلمة-المرور' | sha256sum
npx wrangler d1 execute exam_review_db --remote --command "INSERT INTO teachers(email,password_hash,name) VALUES ('teacher@gmail.com','HASH_HERE','المعلم');"
```

كلمة المرور لا تُخزّن كنص صريح؛ يُخزّن هاش SHA-256. في تطبيق إنتاجي حساس، يُفضّل لاحقًا استبدال ذلك بنظام هاش أقوى مثل PBKDF2 أو bcrypt عبر بيئة تدعم ذلك.

## النشر على Cloudflare Pages

أنشئ مشروع Pages جديدًا، واربط مستودع Git أو ارفع مجلد المشروع. لأن الواجهة لا تحتاج build معقدًا، اجعل **Build command** فارغًا، واجعل **Output directory** هو `.` أو مجلد المشروع بحسب طريقة الربط. من إعدادات المشروع، اربط قاعدة D1 بالـ binding المسمى `DB`. أضف متغيرًا سريًا باسم `SESSION_SECRET` بقيمة عشوائية طويلة، ولا تضع القيمة الحقيقية داخل Git.

بعد النشر، طبّق `schema.sql` على قاعدة الإنتاج، ثم أضف حساب المعلم. اختبر تسجيل الطالب، ثم تسجيل المعلم، وإضافة سؤال، وبدء امتحان وتسليمه.

## ملاحظات النسخة الأولى

الأسئلة المقالية تُحفظ في `attempt_answers.answer_text`، ولا تدخل في الدرجة الآلية. التصميم يترك مكانًا لإضافة تصحيح يدوي أو تصحيح بالذكاء الاصطناعي مستقبلًا. في هذه النسخة، زمن الامتحان التجريبي الافتراضي 15 دقيقة، ويمكن تحويله لاحقًا إلى جدول امتحانات وإعداد يحدده المعلم.

لأمان أعلى، يمكن في مرحلة لاحقة إضافة CSRF protection، وتحديد معدل المحاولات، وتغيير آلية تسجيل الطالب من الاسم والبريد فقط إلى رمز تحقق أو كلمة مرور.
